# rime

A cargo-compatible build system for Rust, written in Zig, that shares all
build artifacts through one **bounded, content-addressed global store** —
instead of growing a `target/` directory until the disk fills.

## Status

Complete and green: `zig build test` hermetic **and** `RIME_CARGO_ORACLE=1`
(the conformance suite that builds the validation corpus with real cargo and
rustc and byte-compares results).

Implemented subsystems:

- **Storage core** — BLAKE3 content-addressed store, clone-first
  materialization (APFS `clonefile` / `FICLONE`, never hardlinks), roots +
  LRU/age GC, cold gzip tier.
- **Very bounded storage** — one total budget (default `clamp(10% free,
  5 GiB, 50 GiB)`) with hard class allocations (70/20/5/5), write-time
  admission control (`reserve → evict unrooted LRU → demote → StoreFull`
  with a budget breakdown). Invariant: total bytes ≤ budget at all times.
- **Metadata + tagging index** — vendored SQLite; objects tagged with
  `crate`, `crate_version`, `toolchain`, `target`, `profile`, `features`,
  `project`, `action`, `user.*`. Tag queries drive reuse and cleanup
  (`rime cache stat --by-tag`, `rime gc --tag`).
- **Global caches only** — no project-local cache state; `target/` holds
  only materialized deliverables (excluded from the budget).
- **Cargo compatibility** — `Cargo.toml` (broad surface incl. workspaces,
  inheritance, `[patch]`, `[replace]`), `Cargo.lock` read + **byte-stable v4
  write**, cargo-conformant resolver (semver, yanked, feature unification
  v1/v2, `cfg` matching) pinned to rust-lang/cargo 0.99.0 semantics.
- **crates.io fetch** — sparse index, `.crate` download + checksums, git
  deps, verified against real cargo artifacts by a network oracle.
- **rustc driver** — unit graph, fingerprints, action keys, spool→store
  ingestion, incremental sessions as a bounded class, check mode.
- **Build scripts + proc macros** — cargo's `cargo:` directive protocol,
  DEP_ propagation, rerun fingerprints, sandboxing (macOS seatbelt).
- **CLI parity** — `build/check/test/run/bench/clean/fetch` with cargo's
  exit codes, streaming `--message-format=json` events, `--locked/--frozen/
  --offline`.

## Commands

    rime build [--dry-run] [--message-format=json]   # and check/test/run/bench
    rime clean [-p PKG] [--release|--profile P]
    rime fetch
    rime cache stat [--by-tag k=v]    # usage vs budget, roots, binding constraint
    rime gc [--dry-run] [--tag k=v] [--to-size N] [--older-than D]
    rime pin <name> <digest> / rime unpin <name>
    rime store put <name> <file>      # durable storage (exempt from GC)
    rime store get <name> <out>
    rime cache verify                 # re-hash a sample of stored objects

## Build & test

    zig build test                   # hermetic suite
    RIME_CARGO_ORACLE=1 zig build test   # + real-cargo conformance suite
    zig build

Zig 0.16.0, macOS + Linux.

## Validation corpus

`validation/` holds four real Rust projects (workspace, feature matrix,
lockfile golden, full manifest) with goldens generated by real cargo.
`validation/oracle.sh` re-verifies them. Specs and plans live in `docs/`.
